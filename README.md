# Очередь на сдачу лабораторных работ

Этот телеграм-бот предназначен для организации очереди на сдачу лабораторных работ по трем предметам:
- Теория графов (Дискретная математика)
- Базы данных
- Микроконтроллеры

## Основные функции

### Для студентов:
- 📝 Запись в очередь на сдачу лабораторной работы
  - Выбираете предмет
  - Вводите имя и фамилию
  - Указываете номер лабораторной
  - Подтверждаете данные
- 📊 Просмотр текущих очередей

### Для преподавателя (администратора):
- 🔀 Перемешивание очереди (`/sort` команда)
  - Случайным образом перемешивает студентов в очереди
- 🧹 Очистка очереди (`/clear` команда)
  - Полностью очищает очередь по выбранному предмету
- 👀 Просмотр очередей (`/printq` команда)
  - Выводит текущее состояние всех активных очередей

## Как использовать

1. Начните работу с ботом командой `/start`
2. Выберите нужный предмет из предложенных:
   - Очередь на Теорию графов
   - Очередь на Базы данных
   - Очередь на Микроконтроллеры
3. Следуйте инструкциям бота

## Административные функции

Для доступа к административным функциям:
1. Введите команду `/sort` или `/clear`
2. Укажите имя: `khidir`
3. Укажите фамилию: `karawita`
4. Введите пароль: `1827tT`

После этого вы сможете:
- Перемешивать очереди
- Очищать очереди
- Просматривать текущее состояние очередей

## Техническая информация

Бот использует:
- SQLite базу данных для хранения списка студентов
- Словари Python для управления очередями
- Библиотеку `pyTelegramBotAPI` для работы с Telegram API
